# Vladimir Glazatov — research website

Personal research website of Vladimir Glazatov, applied mathematician and machine learning researcher.

Live site: https://bard0.github.io/

Research topics include finite-step stochastic gradient descent, stochastic optimization, dynamical systems, functional analysis, measure theory, operator methods and mathematical physics.

The site is available in English and Russian and includes publications, selected talks, research summaries, background information and web CVs.

Built as a lightweight static site with HTML, CSS and JavaScript and hosted on GitHub Pages.
